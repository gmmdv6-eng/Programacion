# 💻 Programación — 1º DAM

Repositorio de la asignatura **Programación** (código 0485) del primer curso del
ciclo formativo de grado superior **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Aquí guardo las unidades didácticas, ejercicios, prácticas y proyectos del curso.
El material avanza de forma progresiva: desde los fundamentos de Java hasta la
programación orientada a objetos, colecciones, ficheros y bases de datos.

---

## 🎯 Objetivos de la asignatura

- Comprender la lógica de programación y el diseño de algoritmos.
- Dominar la sintaxis básica de Java.
- Aplicar estructuras de control y de datos para resolver problemas.
- Iniciarse en los principios de la Programación Orientada a Objetos (POO).
- Trabajar con control de versiones profesional (Git/GitHub).

---

## 🗂️ Unidades didácticas

| UD | Tema |
|----|------|
| UD0 | Introducción a la programación. Pseudocódigo |
| UD1 | Introducción al lenguaje Java. Tipos, variables y operadores |
| UD2 | Estructuras de control: condicionales y bucles |
| UD3 | Programación estructurada y modular. Funciones y recursividad |
| UD4 | Estructuras de datos estáticas: arrays, matrices y Strings |
| UD5 | Estructuras de datos dinámicas: colecciones (ArrayList, Set, Map) |
| UD6 | Programación Orientada a Objetos: clases, objetos y encapsulación |
| UD7 | POO avanzada: herencia, polimorfismo, clases abstractas e interfaces |
| UD8 | Ficheros y manejo de excepciones |
| UD9 | Interfaces gráficas con JavaFX |
| UD10 | Acceso a bases de datos con JDBC |

---

## 🧰 Tecnologías y herramientas

- **Lenguaje:** Java (JDK)
- **IDE:** Visual Studio Code
- **Control de versiones:** Git y GitHub

## 📊 Evaluación

El módulo se evalúa por **Resultados de Aprendizaje (RA)**.  Para aprobar es
necesario obtener **al menos 5 en cada RA**. 

| RA | Resultado de aprendizaje |
|----|--------------------------|
| RA01 | Reconoce la estructura de un programa informático |
| RA02 | Escribe y prueba programas sencillos con POO |
| RA03 | Escribe y depura código usando estructuras de control |
| RA04 | Desarrolla programas organizados en clases |
| RA05 | Realiza operaciones de entrada y salida de información |
| RA06 | Manipula información con tipos avanzados de datos |
| RA07 | Aplica características avanzadas de POO |
| RA08 | Utiliza bases de datos orientadas a objetos |
| RA09 | Gestiona información en bases de datos con integridad |
